# 해설·무전 한국어 더빙

실제 사람의 녹음이 아니라 **AI 음성 합성**입니다. 원작 해설자·성우의 목소리를 복제하거나 학습하지 않았습니다.

## 대상
| 묶음 | 파일 | 칸 | 한국어 음성 | 원본 유지 |
| --- | --- | ---: | ---: | ---: |
| 해설(레이스 캐스터·엔지니어 무전·튜토리얼) | `AUDIO/COM/GBR06.WAD` | 8,397 | 8,392 | 5 |
| 테스트 세션 무전 | `AUDIO/COM_TS/TS_GBR06.WAD` | 669 | 668 | 1 |

원본 유지 = 말이 아닌 소리이거나 0.1초 미만인 조각입니다. 영어(GBR) 묶음만 바꿨으므로 **언어 선택에서 ENGLISH(한국어)** 를 고르면 한국어 음성이 나옵니다.

## 1. 받아쓰기 (`tools/voice.py asr`)
- 클립을 PS-ADPCM에서 디코드(`tools/psadpcm.py`, numba 가속)해 faster-whisper로 영어 초안을 만듭니다(무전 small.en, 해설 base.en).
- 짧은 클립을 0.9초 무음을 끼워 약 25초 창으로 이어 붙여 받아쓰고, 단어 시각으로 다시 나눕니다.

## 2. 번역
- 번역기·번역 모델을 쓰지 않고 Claude(Anthropic)가 묶음별로 직접 옮겼습니다.
- 길이: 한국어 음절 수 ≤ 발화 초 × 6(한도 × 7.5). 숫자·영문은 한글 읽기로 적었습니다(예: 0.3초 → 영 점 삼 초).
- 받아쓰기의 잘못 들린 이름은 클립 순서(드라이버 순서가 반복됨)와 문맥으로 바로잡았습니다.
- 해설은 조각(이름만 있는 클립, 서술 꼬리 클립)을 이어 붙이는 구조라 조각마다 자연스럽게 끝나도록 옮겼습니다. 영어 어순을 따르는 곳은 어색하게 들릴 수 있습니다.

## 3. 합성 (`tools/dub_tts.py`)
- Supertonic 3(Supertone) 내장 화자: 해설 **M4**, 무전 엔지니어 **M2**.
- 음절 수와 원본 발화 길이로 속도(0.85~1.6)를 정하고, 넘치면 WSOLA로 최대 1.3배 압축, 그래도 길면 더 빠르게 다시 합성합니다.
- 길이는 원본 이하(원래 자리에 그대로 들어가게), 음량은 원본과 같은 LUFS(ITU-R BS.1770)로 맞추고 리미터를 겁니다(`tools/loudness.py`).

## 4. 게임에 넣기 (`tools/dub_inject.py`)
- 24000Hz PCM을 PS-ADPCM으로 인코딩(마지막 프레임 종료 플래그 1)해 원래 오프셋에 덮어쓰고 IDX의 크기만 고칩니다. WAD·IDX 크기가 그대로라 ISO 안에서 제자리 교체합니다.
- 검증: ISO에서 다시 꺼내 디코드해 합성 음성과 비교(무전 중앙값 22.1dB), PCSX2 녹화로 레이스 출발 해설·무전이 한국어로 나오는 것을 확인했습니다.
