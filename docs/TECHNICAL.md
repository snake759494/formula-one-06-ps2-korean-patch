# 기술 설명

PS2 유럽판 **Formula One 06 (SCES-53950)** 의 데이터 형식과 한글화 방법입니다.

## 1. 디스크
- DVD5, ISO9660 + UDF 브리지. 게임은 파일을 이름으로 찾으므로 파일을 옮기면 ISO9660 레코드와 UDF File Entry를 모두 고칩니다(`tools/iso.py`, `tools/udf.py`).
- 주요 파일: `SCES_539.50`(ELF), `DATA2006/STARTUP.WAD`, `F12006.WAD`(253MB), `CAREER2.WAD`, `AUDIO/COM/GBR06.*`(영어 해설), `AUDIO/COM_TS/TS_GBR06.*`(테스트 세션 무전).
- 수정한 WAD 3개는 ISO 끝으로 옮기고(4.69GB, DVD5 한도 안), 음성 WAD는 제자리에서 덮어씁니다.

## 2. WAD 아카이브 (`tools/wad.py`, `tools/lzss.py`)
- `u32 1, u32 개수` + 16바이트 항목 `[이름 해시][오프셋][풀린 크기][저장 크기]`.
- 이름 해시: 경로를 소문자로, `\`→`/` 로 바꾼 뒤 CRC32 표(0xEDB88320)를 초기값 0으로 돌리고 비트 반전.
- 풀린 크기 ≠ 저장 크기면 LZSS: MSB 우선 비트 플래그, 1 = 8비트 리터럴, 0 = 13비트 절대 창 위치 + 4비트(길이−3). 창 0x2000, 쓰기 위치 1에서 시작.
- 바꾼 항목은 압축하지 않고(두 크기를 같게) WAD 끝에 덧붙입니다.

## 3. 직렬화된 레드-블랙 트리 (`tools/rbt.py`)
글꼴(.bft)과 텍스트(.blf)는 `std::map` 을 그대로 덤프한 형식입니다.
- 머리 7×u32 `[n][n][2][n+1][루트][-1][n+1]`, 노드 포인터 자리(n+2)×4바이트(메모리 잔여물), 노드(n+2)개.
- 노드 꼬리 `[다음][이전][번호][왼쪽][오른쪽][부모][검정]` 은 상대 번호. 노드 0·1은 센티넬.
- 트리 모양은 "정렬된 키를 차례로 삽입한 레드-블랙 트리"와 같아서 다시 만들어 원본과 비트 단위로 일치시켰습니다.

## 4. 텍스트 (`tools/blf.py`)
- `Frontend/Localised/Boot`(24), 메인(2,017 / 2,803), 커리어(1,619) 4종 × 언어별 파일. 노드 40바이트 `[키 해시][문자열 오프셋]…`, 뒤에 UTF-8 문자열 풀.
- 영어 파일의 문자열 풀만 한국어로 다시 씁니다. 게임 언어 선택에서 **ENGLISH** 를 고르면 한국어가 나옵니다.
- 언어 선택 목록은 체크섬이 붙은 Lua 5.1 바이트코드(`mMenuTextItems`)에 있어 길이를 바꿀 수 없습니다. `ENGLISH`(7바이트)를 재배정 코드의 `한국어 `(2바이트×3 + 공백 = 7바이트)로 바꿉니다.

## 5. 글꼴 (`tools/bft.py`, `tools/kfont.py`)
- 노드 72바이트 `[u16 코드][u16][f32 폭, 높이, u0, u1, v0, v1, 전진, x보정][커닝 표 번호]` + 트리 꼬리. eurostyle 계열은 커닝 표가 뒤에 붙습니다.
- 텍스처는 PSMT4를 PSMCT32(폭/2 × 높이/4)로 올리는 GS 패킷(`.pct`). 헤더의 크기·블록 수·DBW·TRXREG·IMAGE 길이를 함께 고칩니다.
- **텍스처는 512×512 이하**여야 합니다. 폭 1024는 한글 영역이 깨지고, 세로 1024는 레이스 쪽 화면(그랑프리 메뉴·로딩)에서 VRAM 자리를 기다리며 게임이 멈춥니다(v1.0의 그랑프리 멈춤). 메뉴 전용 글꼴은 한글 875자, 레이스 쪽에서도 쓰는 4종은 UI 글자 740자를 14px로 넣었습니다.
- **한글 코드 재배정**: 레이스 쪽 텍스트 코드는 U+AC00 이상 문자를 그리지 못하고(빈칸), 드라이버 데이터에 넣으면 레이스 로딩이 멈춥니다. 쓰이는 한글을 U+0250~036F·U+0590~07FF(대소문자 없음, 2바이트 UTF-8)에 차례로 배정해 텍스트·글꼴·데이터베이스·언어 메뉴에 같이 씁니다(`tools/build.py`).
- **팔레트 공유**: eurostyle 중·대형 글꼴은 런타임에 CLUT 하나를 같이 씁니다. 한글 픽셀은 두 팔레트에서 같은 투명도가 나오는 인덱스만 씁니다(`robust_lut`).

## 6. 드라이버·팀 데이터베이스
- `0x873A829C` 에 드라이버·팀 레코드(문자열 블록 + 오프셋 목록)가 있습니다. `tools/dbnames.py` 가 문자열 블록과 헤더의 오프셋 목록을 다시 씁니다. 드라이버는 짧은 표기·표시용 성, 팀은 정식·짧은 이름만 바꿉니다(이름·성 필드는 내부 키로 쓰일 수 있어 그대로 둠). 재배정 코드로 넣어도 **퀵 레이스 로딩이 멈춰서**(그랑프리는 통과) 배포본에서는 이 파일을 원본 그대로 둡니다(`DB_KO=1` 로 실험 가능).

## 7. 음성
- `*.IDX` = `u32 개수` + `[오프셋, 크기]`(없는 칸 0xFFFFFFFF), 데이터는 PS-ADPCM 모노 **24000Hz**, 0x800 정렬, 마지막 프레임 플래그 1.
- 샘플레이트는 PCSX2 녹화 오디오와 원본 클립의 상관(24000Hz 0.835, 22050Hz 0.158)으로 확정했습니다.
- 자세한 과정은 [DUBBING.md](DUBBING.md).
